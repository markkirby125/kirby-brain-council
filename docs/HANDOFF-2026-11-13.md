# Handoff: brain-council skill, 2026-11-13

## What it is
The skill folder (SKILL.md + references/00..04). A multi-agent "brain" decision council. Plan was approved and built this session.

## Locked design (user decisions)
- Perception gate (P) -> functions F1-F6 in parallel -> Metacognition (M) -> Decision (D) -> 3 blinded voters -> 2-of-3. Red Team joins from round 2.
- Models/effort: P, F1-F6, M, Red Team = opus/high. D = opus/xhigh. Voters = sonnet, opus, haiku, all xhigh (Haiku chosen over Fable for the third voter slot).
- Max 3 rounds, then "the brain could not come up with a definitive decision". 1-1 tie with 2 valid votes = BAD. Irreversible/paid/outward-facing needs all 3 slots valid GOOD (abstain counts as not GOOD).
- Undecidable gate and every failure output stop and ask the user: halt, or perform another run (3-rejection failure adds "accept best attempt").
- Voters run as Agent-tool subagents (user chose this over clean `claude -p`).

## Known open items
- Decisions raised by the real-voter T4. #1-#3 are settled; #4-#7 still need a decision:
  1. SETTLED: `[P]` restart trigger: voters cite `[P]` as supporting evidence in every BAD vote, so "any `[P]` tag re-runs everything from P" would restart each round. The run used the "(framing disputed)" gloss. Applied: the tag that opens a voter's BLOCKING line is its location tag and is the only tag that routes a re-run; REASONS tags are evidence only.
  2. SETTLED: what "tagged" means: leading tag of each REASONS entry, or any tag in REASONS/BLOCKING. The run used any tag; leading-only would have re-run just F1 and F3. Resolved: only the location tag (the tag opening BLOCKING) counts.
  3. SETTLED: STANDING objections allow one tag, but voter objections carry several. Resolved: one location tag per objection; the other tags go in `cites:`.
  4. Three ~50k-character voter briefs in one message is impractical; the spec does not cover relays.
  5. Lane drift: a re-run function given REJECTED plus FIX lines wrote its own DECISION block, so voters saw two decisions. No rule covers a function proposing a decision.
  6. The pre-vote check is presence-only; it passed "cover the emergency on a credit card". Decide whether it should judge substance.
  7. "Accept the best attempt" is offered even when every round scored 0/3 GOOD on an IRREVERSIBLE decision. Decide whether a floor applies.
